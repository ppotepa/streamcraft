# 1.1 Widget Editor Modal

## Purpose
Focused surface for configuring a widget’s data binding and layout without cluttering the canvas.

## Layout
- **Header**: Widget title, Cancel, Save.
- **Basics section**: Source, Endpoint, Field, Format; Test button (per widget).
- **Layout section**: X, Y, Width, Height numeric fields; note about drag/resize on canvas.

## Interactions
- Open: double-click a widget on canvas.
- Live preview of the widget stays on canvas while editing; changes apply on Save.
- Cancel/backdrop closes without committing edits.
- Test button invokes `/public-api-sources/test` for the selected source/endpoint.

## Data flow
- Draft state created from the selected widget on open; merged back on Save.
- Fields are sourced from metadata or typed models; default field picks first leaf.

## Known gaps
- No undo/redo within modal; no diff/revert button beyond Cancel.
- No per-field validation beyond select presence; no type-aware formatting hints.
- No CSS/style editor yet (future enhancement for custom styles).
