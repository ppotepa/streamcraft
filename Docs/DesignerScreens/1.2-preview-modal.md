# 1.2 Preview Modal

## Purpose
Read-only overlay preview against motion background to judge contrast, spacing, and composition.

## Layout
- **Backdrop**: Dim/blur layer.
- **Window**: Video element (looped sample) with overlay layer on top.
- **Overlay**: Renders all current widgets with pointer-events disabled.
- **Close**: Button to dismiss (backdrop click also closes).

## Interactions
- Open via header “Preview” button on the main designer.
- View-only; no drag/resizing; no edits inside this modal.

## Data
- Uses current in-memory widget list and triggers fresh fetches for each bound source/endpoint when opened so live values appear.
- Shows same widget rendering as canvas but without selection chrome.

## Known gaps
- Uses sample video only; no per-project or per-game background yet.
- No device/aspect presets; relies on current canvas sizing CSS.
- No per-widget live data refresh trigger; depends on prior preview/test payloads.
